# Expense-Tracker
Подсчет расходов
**Автор:** Калабушкин Дмитрий Алексеевич

## Описание программы

Expense Tracker — это GUI‑приложение для учёта личных расходов с возможностью:
* добавления расходов (сумма, категория, дата);
* фильтрации по категории и периоду;
* подсчёта общей суммы за выбранный период;
* сохранения данных в JSON‑файл.

## Как использовать

1. Запустите приложение: `python main.py`.
2. Заполните форму:
   * **Сумма** — введите положительное число.
   * **Категория** — выберите из списка или введите свою.
   * **Дата** — укажите в формате `ГГГГ‑ММ‑ДД` (по умолчанию — текущая дата).
3. Нажмите **«Добавить расход»** — запись появится в таблице.
4. Для фильтрации:
   * выберите категорию из выпадающего списка;
   * укажите даты «С» и «По»;
   * нажмите **«Применить фильтры»**.
5. Внизу отображается **общая сумма** отфильтрованных расходов.

## Примеры использования

**Тест 1. Добавление расхода**
1. Сумма: `1500`.
2. Категория: `Еда`.
3. Дата: `2024-05-15`.
4. Нажмите «Добавить расход».
5. Проверьте, что запись появилась в таблице, а сумма обновилась.

**Тест 2. Фильтрация**
1. Установите фильтр: категория `Еда`, дата «С» `2024-05-01`, «По» `2024-05-31`.
2. Нажмите «Применить фильтры».
3. Убедитесь, что отображаются только расходы на еду за май 2024 года.

## Технические детали

* **Язык:** Python 3.x.
* **GUI‑библиотека:** Tkinter (встроена в Python).
* **Хранение данных:** JSON‑файл `expenses.json`.
* **Кодировка:** UTF‑8 (поддержка кириллицы).
